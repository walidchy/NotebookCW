# 🧠 NotebookCW

NotebookCW is an intelligent PDF document analysis and summarization tool with optional image generation.
Users can upload PDFs, ask questions about the documents, generate summaries, quizzes, and now generate images using the Subnp Free Image API.

---

## Features

- Upload PDF documents
- Generate:
  - Summaries
  - Quizzes (Multiple Choice)
  - Briefings
- Ask questions about uploaded documents
- Generate images from text prompts using the Subnp Free Image API

---

## Technologies

- Backend: Node.js, Express
- Frontend: React
- AI API: Groq (for document analysis)  
- Image Generation API: [Subnp Free API](https://subnp.com/fr/free-api)
